# Referências de voz (Chatterbox)

Coloque aqui `orlando_ref.wav` e `duda_ref.wav` (10 a 20 s, fala limpa) **só
com direito de uso comprovado**, registrado em `LICENSES.md` (quem gravou,
autorização por escrito, data). Nunca use voz de pessoa pública ou de terceiro
sem autorização.

Sem arquivo aqui, o Chatterbox usa a voz padrão embutida no modelo.
